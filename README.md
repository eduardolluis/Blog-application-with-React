# React Blog Application

A React blog project built to practice component-based UI development and client-side routing.

## Features

- Blog feed
- Routed pages with React Router
- Individual post views
- Post editing flow
- About page
- Date formatting with `date-fns`

## Tech Stack

- React 18
- React Router
- JavaScript
- CSS
- date-fns
- Create React App

## Run Locally

```bash
git clone https://github.com/eduardolluis/Blog-application-with-React.git
cd Blog-application-with-React
npm install
npm start
```

Create a production build with:

```bash
npm run build
```
